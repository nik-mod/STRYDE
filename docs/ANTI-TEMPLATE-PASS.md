# STRYDE: focused design-quality pass

## Evidence and direction

The fresh audit reviewed all eight homepage chapters, the concept index, the native collection and product fixture, and search. Baseline captures are in `.work/anti-template/`. The established blue/cyan palette, Archivo family, diagonal Hero, Materials macro sequence and image-led Brand composition remain the visual foundation.

The remaining weaknesses were specific: repeated motivational copy competed with the product; view captions concealed which angle was shown; circular navigation and capsule actions added unnecessary chrome; lists and catalog entries repeated the same entrance motion; product and catalog headings inherited campaign typography that delayed practical browsing.

The pass used the frontend implementation workflow, Impeccable's polish/distill/clarify and craft guidance, the GSAP reference and photographic composition principles. Impeccable context loading was unavailable; existing project documents and rendered evidence supplied the context. The hierarchy decision was to preserve the sneaker and macro image as the focal subjects and give commerce a quieter, precise voice.

## Changes

- Technology now introduces “Lines & layers”; the optional outline word renders only when supplied. Schema defaults describe visible form rather than unsupported performance or material claims.
- The TN view series names its actual images: three-quarter view, heel view and from above. These remain disclosed views of one model, not fabricated product variety.
- Featured uses “Blue / white.” and a short visual observation. Brand's editable two-line composition replaces three imperatives; blank lines produce no display row. Finale names the collection and provides a clear collection action. Existing product bindings and merchant overrides remain authoritative.
- The Hero's TN edition label appears only with its bundled model. Actual products and custom imagery/models receive the chapter number without implying a TN identity.
- The chapter index retains eight links, current state, tooltips and keyboard focus in a narrow rectangular rail. Primary shopping actions have restrained corners. No navigation or commerce capability was removed.
- Product names retain merchant capitalization and use upright, moderate-weight Archivo. Collection, concept-index, search and card typography support scanning. Collection heading, control and count spacing bring the first product row forward. Native filters, pagination, inputs, variants and forms retain their contracts.
- Collection and search counts use localized singular/plural messages. The local preview translator supports the same count and interpolation arguments; escaped search terms remain safe.
- Anatomy lists, phone Materials captions, Technology rows and Featured copy remain readable as static anchors. Image motion, Materials wipes, Brand masks, Collection handoffs, Hero's canonical takeover and the existing scroll architecture remain. Catalog entries no longer rise independently; the static mount still returns safe lifecycle cleanup. Finale's perpetual idle float is removed.
